## Prompt

```text
Using the LottieFiles Creator MCP, create a seamless 6-second looping animation where 500 dots of varying sizes spell out "FABLE 5" using real SVG letterforms, then explode into the X (Twitter) logo and back. Dots should never be fully still,  give them slow elliptical drift while resting in each shape. 

On the transition, each dot should anticipate inward, burst outward along its own curved arc while scaling up and flashing vibrant colors, then settle elastically into the X with overshoot, colored in a teal-to-violet gradient on a dark navy background with a soft glow. 

The return trip should fly each dot back along a, different arc to its exact starting position so every dot is continuously followable, and frame 360 must match frame 0 perfectly for an endless loop.
```
