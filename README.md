# Awesome Fable 5 Motion Design [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

Motion design and motion graphics videos made with **Claude Fable 5**, each with the prompt (or agent skill) behind it. Launch films, kinetic typography, UI motion, animated explainers and more, all written as code.

Every video here was made by asking Claude Fable 5 to write the animation as code (HTML, Canvas, SVG, Remotion, HyperFrames and friends). Pick one, copy its prompt, and make your own.

## How to use a prompt

1. Open a video's **Prompt** link and copy the prompt.
2. Give it to Claude Fable 5 (in a coding agent that can use this model and run code), filling in any placeholders such as your product name.
3. Let it write the animation as code, then render it to video (Remotion, HyperFrames, or a headless browser with ffmpeg).

Want agents that already know timing, easing and choreography? See the [MotionVideo skill](https://motionvideo.xyz/motionvideo-skill?utm_source=github&utm_medium=readme&utm_campaign=awesome-fable-5-motion-design).
